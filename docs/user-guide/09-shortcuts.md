# 09 — Keyboard shortcuts

**Docs last updated:** 2026-07-12

| Shortcut | Action |
|----------|--------|
| **Ctrl+O** | Open project |
| **Ctrl+S** | Save current file |
| **Ctrl+B** | Build Disk |
| **Ctrl+R** | Run in XRoar |
| **Ctrl+Shift+D** | Run Diagnostics (build + focus Problems) |
| **Ctrl+Q** | Quit (platform-dependent; also File → Quit) |
| **F1** | Open User Guide |
| **Ctrl+Shift+O** | Browse Disk Image |
| **Ctrl+Shift+A** | Assemble ASM only |

Standard OS text-editing shortcuts apply in the editor (copy/paste/undo via the toolkit).
