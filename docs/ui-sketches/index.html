Main window — design notes
  • Toolbar stays thin: Open/Save, Build Disk, primary Run in XRoar, then secondary tools.
  • Target chip (top-right) is always visible: machine · RAM · dialect · active .dsk.
  • Three columns default: project tree | editor + problems | live disk image (first-class, not a dialog).
  • Modern / CoCo toggle on the editor tab bar switches between preprocessor source and expanded CoCo BASIC (line numbers + short vars).
  • Bottom panel collapses to one of: Problems · Build log · XRoar output.

Preprocessor UI
  • Primary edit surface is modern source; CoCo form is a build artifact (viewable, optional side-by-side).
  • Features: auto line numbers, long→2-char (or unique short) vars, procedure→GOSUB/RETURN, labels→line numbers.
  • Variable map panel (toolbar) lets you pin preferred short names and shows collisions before build.
  • Diagnostics run on both: modern semantics + post-expand CoCo rules (memory, keywords, machine).
  • Users can still write classic numbered BASIC with preprocessor off — zero surprise.
